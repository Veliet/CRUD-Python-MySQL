## CRUD – Python e MySQL

Projeto desenvolvido para implementar as operações básicas de um CRUD (Create, Read, Update e Delete), utilizando Python e MySQL.

## Objetivo

Conexão com MySQL utilizando Connector.
Criação do banco de dados e das tabelas pelo Python.
Organização do código em módulos.
Função auxiliar para evitar repetições.
Tratamento de erros utilizando try/except.

## Upgrade

Interface com Flask.
Páginas em HTML.
Estilização com CSS.

## Tecnologias
Python
MySQL
MySQL Connector
* Flask
* HTML e CSS
