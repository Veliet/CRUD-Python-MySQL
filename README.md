# CRUD de Cadastro de Pessoas

Projeto simples em **Python** utilizando **SQLite3** para realizar operações de **CRUD** (Create, Read, Update e Delete) em um cadastro de pessoas via terminal.

## Tecnologias

* Python
* SQLite3

## Funcionalidades

* Cadastrar pessoas
* Listar registros
* Atualizar cadastros
* Excluir registros
* Validação básica de entradas
